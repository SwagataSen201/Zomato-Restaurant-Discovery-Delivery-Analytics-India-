# Zomato-Restaurant-Discovery-Delivery-Analytics-India 🍽️

> A product analytics project exploring restaurant supply, discovery, affordability, ratings, customer engagement, and online delivery across India using historical Zomato data.

---

## Overview

This project explores the Indian restaurant marketplace from a **product analytics perspective**.

Instead of simply asking questions about the dataset, the analysis focuses on how restaurant supply, cuisine availability, ratings, affordability, customer engagement, and online delivery can shape the restaurant discovery experience.

The project uses SQL to turn these product questions into measurable analysis.

> **Dataset note:** This project uses historical Zomato restaurant data. The results should not be interpreted as a representation of Zomato's current 2026 marketplace.

---

## The Problem

For a restaurant discovery platform, users need to find restaurants that fit their:

* Location
* Cuisine preferences
* Budget
* Quality expectations
* Ordering needs

At the same time, the marketplace needs a healthy supply of restaurants across cities and categories.

This project explores the data behind these different parts of the marketplace.

---

## Product Questions

The analysis focuses on eight questions:

1. Which Indian cities have the highest restaurant supply?
2. Which cuisine combinations are most common?
3. Which cities have the highest rating coverage?
4. How does restaurant rating vary across price segments?
5. Do higher-rated restaurants receive more customer engagement?
6. Which restaurants combine good ratings, reasonable prices, and meaningful engagement?
7. Which cities have the highest online-delivery adoption?
8. Which cities have substantial restaurant supply but relatively low online-delivery adoption?
